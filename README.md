# Hand Gesture Recognition using Convolutional Neural Network (CNN)

## Internship Task – Prodigy Infotech (Task-04)

This project implements a Hand Gesture Recognition system using a Convolutional Neural Network (CNN) trained on the LeapGestRecog dataset. The model is capable of recognizing and classifying different hand gestures from images, enabling gesture-based human-computer interaction.

---

## Project Overview

Hand gesture recognition is an important application of computer vision that enables machines to understand human gestures. This project uses deep learning techniques to build an accurate gesture classification model.

The model is trained on thousands of labeled gesture images and learns patterns using convolutional layers.

---

## Dataset Information

Dataset used: LeapGestRecog  
Source: https://www.kaggle.com/datasets/gti-upm/leapgestrecog  

Dataset contains:

- 10 different subjects
- 10 gesture classes
- 20,000 total images
- Grayscale gesture images

Example gesture classes include:

- Palm
- Fist
- Thumb up
- Thumb down
- Index
- OK gesture
- And others
